One letter, K — for knackered: flat-out exhausted, collapsed on the sofa after a long day. This program writes exactly one character, the letter K, to /output/entry.txt for make.fun's "One Letter for Your Day" bounty, where a judge picks the letter whose hidden word feels most vivid, funniest or truest.

## Run it

```sh
python3 main.py
```
